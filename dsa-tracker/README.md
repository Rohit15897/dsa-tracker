# DSA Progress Tracker

A simple, interactive web app to track your progress solving Data Structures & Algorithms problems. Monitor coverage across topics and difficulty levels, and balance your practice.

## 🚀 Quick Start

1. **Open the app**: Double-click `index.html` in your browser (or drag it into your browser)
2. **Add problems**: Fill in the form and click "Add Problem"
3. **Track progress**: View all problems in the table below, filter by difficulty or topic
4. **Monitor stats**: Check the sidebar for real-time statistics on your progress

## ✨ Features

- **Add/Edit/Delete** problems easily
- **Filter** by difficulty (Easy, Medium, Hard) and topic
- **Track status**: To Do, In Progress, Solved, Revisit
- **Auto-date**: Automatically records when you mark a problem as Solved
- **Summary dashboard**: Real-time stats by difficulty, status, and topic
- **Persistent storage**: Your data is saved in browser storage (survives page refreshes)
- **No backend needed**: Runs entirely in your browser

## 💾 Data Storage

All your problems are saved in your browser's local storage. This means:
- ✅ Data persists across browser sessions
- ✅ No login needed
- ✅ No server or internet connection required
- ⚠️ Data is stored only in this browser (not synced across devices)

If you want to back up your data, check your browser's developer tools and export from local storage.

## 🔧 Customization

You can easily customize this tracker:
- **Add more topics**: Edit the topic dropdown in the HTML
- **Change colors**: Modify the CSS variables in the `<style>` section
- **Add new fields**: Extend the problem object and form fields

## 🎯 Tips for Effective Tracking

1. **Be consistent**: Add problems as you work through them
2. **Add notes**: Include the approach or patterns you used
3. **Review regularly**: Check your stats to identify gaps in coverage
4. **Revisit problems**: Mark tricky ones as "Revisit" to practice later
